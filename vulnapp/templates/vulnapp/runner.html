Try these payloads

  • print("hello") - looks harmless
  • import os print(os.getcwd()) print(os.listdir('.')) - read the filesystem
  • import os print(os.popen('whoami').read()) - run an OS command as the server user

Why this can't really be "fixed" with more checks

Unlike the calculator, there's no safe subset of "run any statements" that still lets users write general programs. The only real fixes are: don't execute untrusted code at all, or isolate it in a proper sandbox (separate unprivileged process/container with no filesystem, network, or secrets access, plus CPU/time/memory limits) - never eval()/exec() on raw input, and never assume a Python-level "blacklist" of dangerous names is enough (attackers can always find another path to __import__ or __builtins__).
